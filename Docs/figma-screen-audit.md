## 직접 확인한 차이

현재 총 66개 프레임 중 앱 화면 65개는 Figma 원본과 시뮬레이터 캡처를 직접 대조했습니다. H1은 iOS 잠금화면 알림이라 디자인과 알림 모델을 대조했지만 실제 푸시 수신 화면은 검증하지 못했습니다. 대조 완료는 모든 픽셀이 완전히 같거나 서버 기능이 연결되었다는 뜻이 아니며, 확인된 차이는 아래에 기록합니다.

## 화면별 완료 기록
